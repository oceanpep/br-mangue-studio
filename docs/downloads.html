Linux research preview

BR-MANGUE Studio 1.1.0 for Linux.

The interface is available in English and Brazilian Portuguese. The x86_64 build was created on Ubuntu 22.04 LTS and launched successfully on Ubuntu 26.04.1 LTS. Full raster loading and simulation workflows still need broader Linux validation. Ubuntu 24.04, Linux Mint 22, and Debian 13 are expected to work, but have not been individually tested. Other x86_64 distributions with glibc 2.35 or newer may work. Alpine Linux (musl) and ARM64 are not supported by this build.

Use a graphical desktop session (X11 or Wayland). The application bundles Python and project libraries; xdg-open is needed to open result files and folders.
