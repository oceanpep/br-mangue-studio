BR-MANGUE Studio 1.4.10

A ready-to-run Windows application for spatial cellular modelling of mangrove response to sea-level rise.

  • Windows 10 or Windows 11, 64-bit
  • Continuous and persistent-block processing engines
  • Explicit mapping for source classes and optional source-legend labels
  • Migrated mangrove can enter the flooded-mangrove state
  • Integrated maps, animation, charts, and CSV outputs
  • English and Brazilian Portuguese interface
  • Startup citation notice and contact information in Help

Linux research preview

BR-MANGUE Studio 1.4.10 for Linux.

The interface is available in English and Brazilian Portuguese. The x86_64 package was built and smoke-checked on Ubuntu 22.04 LTS. Ubuntu 24.04, Linux Mint 22, Debian 13, Alpine Linux, and ARM64 have not been individually verified; Alpine Linux (musl) and ARM64 are not supported by this build.

Use a graphical desktop session (X11 or Wayland). The application bundles Python and project libraries; xdg-open is needed to open result files and folders.
