How the Studio scales on a real coastal grid.

A reproducible comparison of continuous and persistent-block processing using the CMMA land-cover raster and ANADEM elevation data for Maranhão Island, Brazil.

The benchmark covers ten annual transitions from 2025 to 2035. Each engine was run three times with the same inputs and parameters; the values below report the median elapsed time. Annual GeoTIFF snapshots were disabled so the comparison measures simulation work rather than export time.

Input and scenario

MapBiomas Collection 11, band 41 (2025), plus ANADEM 30 m elevation and the organized study-area mask. Tide influence: 6.0 m. Sea-level rise: 0.3 mm/year. Soil/suitability layer disabled; migration fallback enabled.

What the check tells us

The two engines produced byte-identical final GeoTIFFs and identical annual trajectories. This verifies implementation equivalence and gives a transparent performance reference; it is not an ecological validation or a universal hardware limit.

Host used for the measurement: Intel Core i3-1215U with 19.7 GiB total RAM. Actual times will vary with CPU load, storage, output settings, and raster size. Continuous is the faster choice when the grid fits comfortably in memory; blocks is the safer workflow for very large projects.
