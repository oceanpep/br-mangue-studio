## Benchmarks and reproducibility

- [Reproducibility and benchmarking protocol](REPRODUCIBILITY_AND_BENCHMARKING.md)
- [Linux pilot: Ilha do Maranhão, 2025–2100](benchmarks/ILHA_LINUX_20261001.md)
- [Windows CMMA audit: 2024–2100](benchmarks/CMMA_WINDOWS_2024_2100_20261001.md)
- [Large-grid Linux record](benchmarks/ILHA_LINUX_2025_2100.json)
- [Engine comparison and model-rule audit](ENGINE_COMPARISON_20260909.md)

The Windows CMMA files show roughly four hours per engine and 76 annual
outputs per run. Their class mappings differ, so those timings are not a
controlled continuous-versus-block comparison. The Linux Ilha pilot used the
same inputs and settings for both engines and found no differences across its
75 annual states; it is a computational check, not ecological validation.
