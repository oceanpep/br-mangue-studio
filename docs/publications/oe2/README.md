# CMMA supporting data

This directory contains machine-readable data for the CMMA mangrove simulations.

- [`supporting-data.zip`](supporting-data.zip): scenario trajectories, annual summaries, class mappings, run metadata, and related tabular data.
- [`municipios_manguezais_cmma_2025.xlsx`](municipios_manguezais_cmma_2025.xlsx): mangrove area by municipality, with state and study-area totals.

The archives omit absolute paths from the author's computer. Source rasters are not included. A separate copy of the municipal dataset and its method description is available in [`datasets/cmma_municipalities_2025`](../../../datasets/cmma_municipalities_2025/README.md).
