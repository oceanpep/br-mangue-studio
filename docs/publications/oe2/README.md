# OE2 manuscript and supplementary material

**Manuscript title:** *Modelagem dos manguezais da costa macrotidal da Amazônia sob cenários de elevação do nível do mar até o final do século XXI.*

The article is being prepared for submission to *Mercator* and has not yet been submitted.

- [`manuscript/main.pdf`](manuscript/main.pdf): current article review copy.
- [`manuscript/main.tex`](manuscript/main.tex): editable article source; the accompanying vector figures are in [`manuscript/figuras/`](manuscript/figuras/).
- [`supplementary-material.pdf`](supplementary-material.pdf): current supplementary material, including method details, tables, performance data, and a figure.
- [`manuscript/suplemento.tex`](manuscript/suplemento.tex): editable LaTeX source for the supplementary material.
- [`supporting-data.zip`](supporting-data.zip): class mappings, scenario trajectories, annual series, execution metadata, municipal inventory, and related machine-readable files.
- [`municipios_manguezais_cmma_2025.xlsx`](municipios_manguezais_cmma_2025.xlsx): direct-download version of Supplementary Spreadsheet S1, listing municipal mangrove area.

The supporting-data archive omits absolute paths from the author's computer. The source rasters are not included; see the manuscript for their providers and citations. All PDFs and LaTeX sources in this directory correspond to the same current manuscript revision.
