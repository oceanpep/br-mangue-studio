# OE2 supplementary material

**Manuscript title:** *Modelagem dos manguezais da costa macrotidal da Amazônia sob cenários de elevação do nível do mar até o final do século XXI.*

This directory provides the supplementary PDF and machine-readable files associated with the OE2 manuscript.

- [`supplementary-material.pdf`](supplementary-material.pdf): supplementary methods, tables, and figure.
- [`supporting-data.zip`](supporting-data.zip): class mappings, scenario trajectories, annual series, metadata, and related machine-readable files.

The supporting-data archive omits absolute paths from the author's computer. The source rasters are not included; see the manuscript for their providers and citations.

The manuscript is being prepared for submission to *Mercator*. This repository copy is the supplementary package for the current manuscript version.
