# OE2 manuscript source

This is the editable LaTeX source for the current OE2 manuscript prepared for submission to *Mercator*. It has not yet been submitted.

- `main.tex` is the article source; `main.pdf` is its compiled review copy.
- `suplemento.tex` is the supplementary-material source; the compiled file is stored one level up as [`supplementary-material.pdf`](../supplementary-material.pdf).
- `figuras/` contains the vector figures required to compile both sources.
- `../supporting-data.zip` contains machine-readable inputs, trajectories, annual results, metadata, and municipal inventory.

Compile `main.tex` or `suplemento.tex` as separate documents. The article cites the current repository publication folder for supplementary files and supporting data.
