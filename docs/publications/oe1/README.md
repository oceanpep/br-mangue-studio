# OE1 technical supplement

This directory contains Supplementary Information S1 for the BR-MANGUE Studio software paper (OE1).

The supplement documents the mathematical and computational specification of **BR-MANGUE Studio v1.4.4**. It distinguishes equations and ideas published in earlier sources from rules implemented in the current software. The model specification is tied to the exact software release and DOI [10.5281/zenodo.23527116](https://doi.org/10.5281/zenodo.23527116).

- [Supplement PDF](supplement.pdf)
- [Editable LaTeX source](supplement.tex)

The current document is a Portuguese working draft for author review. The JOSS submission version will need to be translated into English and checked by all authors.

The OE1 working manuscript directs readers to `docs/publications/oe1/` in the repository. The supplement source was checked against `src/brmangue_lua/engine.py`, `src/brmangue_lua/persistent_blocks.py`, `src/brmangue_lua/model_states.py`, and `src/brmangue_lua/sea_level.py`.

The software repository's release history and the code for each release remain the version-specific sources of truth. A later release may change behavior and requires a corresponding supplement update.
