The project

A practical home for the BR-MANGUE model

The Studio preserves the model rules from the reference implementation while providing a portable workflow for raster inputs, class mapping, simulation monitoring, and annual outputs.

01

Use your own data

Load any aligned categorical land-cover raster, elevation model, optional soil layer, and study-area mask.

02

Inspect every run

Follow maps, class counts, trajectories, transitions, and resource usage while the simulation runs.

03

Keep results reproducible

Each run records its inputs, parameters, processing engine, annual states, and metadata.
