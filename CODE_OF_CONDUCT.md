# Code of Conduct

BR-MANGUE Studio is a research software project. Participants are expected to
be respectful, constructive, and inclusive in issues, discussions, reviews,
and pull requests.

Unacceptable behavior includes harassment, discrimination, personal attacks,
publishing private information without permission, and deliberately
disrupting the project or its community.

Report a concern privately to the project maintainers through the contact
information associated with the repository. Reports will be handled in good
faith and as confidentially as practical.
