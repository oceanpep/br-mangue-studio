# Support

For a reproducible bug, open a GitHub issue and include:

- BR-MANGUE Studio version;
- Windows or Python version;
- processing engine and block size;
- raster dimensions, resolution, CRS, and active-cell count;
- the exact error message;
- `metadata.json` or a short description of the run configuration when
  possible.

Do not upload restricted, personal, or unpublished raster data. Replace local
paths and remove sensitive metadata before attaching files.

Questions about ecological interpretation, parameter calibration, or a study's
scientific conclusions should be described as research questions rather than
software bugs.
