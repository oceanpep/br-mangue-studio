# BR-MANGUE Studio — Linux x86_64

## Português (Brasil)

1. Extraia a pasta para um local onde deseja manter o programa.
2. Abra **BRMANGUE_Studio_Linux_x86_64**. Se necessário, nas propriedades do
   arquivo, permita sua execução como programa.
3. No aplicativo, selecione **Ajuda → Criar atalhos no Linux**.
4. Abra o programa pelo menu de aplicativos ou pelo atalho **BR-MANGUE Studio**
   criado na mesma pasta. Também será criado um atalho na área de trabalho
   quando ela estiver configurada no sistema.

Os atalhos usam o logotipo do programa. A janela também recebe o ícone.
Mantenha a pasta no local escolhido; se movê-la, abra o executável no novo
local e crie os atalhos novamente. O programa inclui Python e suas
bibliotecas. Não é necessária uma instalação como administrador.

Como alternativa, execute `./Install_shortcuts.sh` em um terminal aberto
nesta pasta. Caso o gerenciador de arquivos solicite **Permitir iniciar** no
atalho, selecione essa opção. Alguns ambientes Linux não mostram ícones na
barra de título; o atalho e o menu continuam disponíveis com o logotipo.

## English

1. Extract the folder to the location where you want to keep the application.
2. Open **BRMANGUE_Studio_Linux_x86_64**. If necessary, allow execution in the
   file's Properties.
3. In the application, choose **Help → Create Linux shortcuts**.
4. Open the application from your applications menu or the **BR-MANGUE Studio**
   shortcut created beside the executable. A desktop shortcut is also created
   when your desktop directory is configured.

The shortcuts and application window use the program logo. Keep the folder
in the selected location; if you move it, open the executable at its new
location and create the shortcuts again. Python and required libraries are
included. No administrator installation is required.

Alternatively, run `./Install_shortcuts.sh` in a terminal opened in this
folder. If your file manager asks you to **Allow Launching** the shortcut,
choose that option. Some Linux desktops do not show title-bar icons; the
launcher and applications menu still display the logo.
